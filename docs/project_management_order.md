# 과제 관리 순서

과제 카드의 왼쪽 손잡이를 드래그하여 진행중/완료 목록 각각의 순서를 변경합니다. 상태가 다른 목록으로 드래그해도 상태는 변경되지 않습니다. 손잡이에 포커스를 두고 위/아래 방향키로 이동할 수도 있습니다.

과제명 오름차순 버튼은 현재 파트의 두 상태 목록을 각각 한국어 이름순으로 정렬합니다. 숫자는 자연 순서로 비교합니다(과제 2, 과제 10). 정렬은 project.sort_order에 저장되며 새로고침과 다른 화면에서도 유지됩니다.

PUT /api/teams/{team_id}/team-projects/order
project_ids는 현재 범위의 전체 일반 과제 ID를 정확히 한 번씩 포함해야 합니다. expected_ids는 사용자가 보고 있던 원래 순서이며 서버와 다르면 409로 거절합니다. 타 팀/파트, 추가/삭제 및 동시 정렬 충돌을 검증합니다. 서버 저장 성공 후에만 화면에 반영하고 실패 시 최신 목록을 다시 불러옵니다.
