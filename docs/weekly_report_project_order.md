# 주간보고 작성 과제 순서

주간보고 작성 화면의 작성 과제 왼쪽 손잡이를 드래그하거나 위/아래 방향키로 순서를 바꿉니다. 기타 업무는 별도 영역을 유지합니다.

순서는 project_entry.sort_order에 개인별·보고 주간별로 저장합니다. 기존 데이터에는 이전 표시 순서대로 값을 채우며 새 항목은 뒤에 추가합니다. 작성 완료 표시와 관계없이 포함된 정규 과제를 재정렬할 수 있습니다. 보고를 다시 열거나 완성된 HTML 보고서를 볼 때도 같은 순서를 따릅니다.

정렬은 본문, 첨부, 선택한 과제, 미저장 입력, 작성/완료 시각을 변경하지 않습니다. 과제 관리의 전역 순서와도 독립적입니다. 완료 처리된 보고 주간은 다시 열어야 수정할 수 있습니다.

PUT /api/report-entries/{entry_id}/project-order
project_ids와 expected_ids는 현재 포함된 정규 과제 전체를 한 번씩 담습니다. 중복, 누락, 외부 과제, 순서 충돌 및 파트 범위를 검증하며 오류 시 원래 화면 순서를 유지합니다.
