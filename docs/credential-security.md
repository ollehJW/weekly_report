# 계정 비밀번호 발급 및 초기화

- 공통 초기 비밀번호를 사용하지 않습니다. 팀 계정 생성·초기화는 로그인한 관리자만 가능합니다.
- 멤버 생성·비밀번호 설정·초기화는 해당 팀의 로그인 세션 또는 관리자 세션이 필요합니다.
- 계정마다 난수 임시 비밀번호를 발급하고 DB에는 해시만 저장합니다. 발급 응답은 캐시하지 않으며 일반 목록에서 비밀번호를 반환하지 않습니다.
- 발급 창에서 복사하거나 전달용 파일을 다운로드한 뒤 해당 사용자에게 안전하게 전달합니다. 전달 파일은 사용 후 삭제합니다.
- 임시 비밀번호는 24시간 후 만료됩니다. 재발급 시 이전 비밀번호는 즉시 무효화됩니다.
- 팀 로그인 및 멤버 보고 작성 인증은 임시 비밀번호만으로 완료되지 않습니다. 12자 이상의 새 비밀번호를 설정해야 합니다.
- 팀 비밀번호 초기화 시 기존 로그인 세션을 종료합니다. 본인 계정은 사이드바의 비밀번호 변경 기능을 사용합니다.
- 기존 공통 초기 비밀번호는 허용하지 않습니다. 해당 계정은 관리자가 임시 비밀번호를 재발급해야 합니다.
- 인증정보 관리 API의 인증/권한 검증을 보완한 변경이며 다른 모든 API의 접근통제나 배포 TLS 구성을 포괄적으로 변경한 것은 아닙니다.

검증: `python -W ignore::DeprecationWarning -W ignore::ResourceWarning -m unittest discover -s tests -v`, `npm run build`.
